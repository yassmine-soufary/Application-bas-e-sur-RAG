# Visuels décoratifs

Ces deux images ont été créées avec l'outil intégré `imagegen` à partir de la capture fournie comme référence de style. Elles servent uniquement à l'habillage du frontend et ne sont jamais indexées ou présentées comme des sources documentaires.

- `assistant-eih.png` : assistante féminine stylisée, cheveux violets en chignon, lunettes rondes, sweat universitaire blanc avec écusson H, sourire et main ouverte vers la droite. Illustration douce en relief, fond transparent, palette violet/bleu nuit.
- `campus-eih.png` : visualisation architecturale décorative d'une école d'ingénieurs fictive, façade claire, baies vitrées bleues, végétation et arbres roses, panneau EIH. Ce visuel n'est pas une photographie d'un établissement réel ; la légende de l'interface le précise.
